# Kaizen

A TPS-inspired set of skills for improving outcomes in software and workflows. Use one when useful; the four are not a mandatory pipeline.

- **kaizen-establish-value:** clarify a missing or drifting user outcome.
- **kaizen-observe-flow:** trace a real journey and find friction or guidance drift.
- **kaizen-investigate-gap:** investigate a failure and compare proportionate options.
- **kaizen-improve-verify:** consider and verify a change, including removal.

Try: “Use Kaizen to find why this green test suite misses a clunky onboarding journey.” Or: “Use Kaizen to review whether these tests and agent instructions still serve the project.”

In Claude Code, invoke a skill directly as `/kaizen:<skill-name>`, for example `/kaizen:kaizen-observe-flow`. Install with `/plugin install kaizen --marketplace ezhou89/kaizen`.

An audit is read-only unless changes are authorized; diagnosis alone does not authorize edits or deployment. Passing checks do not establish actual user success. Skills use the evidence and access available in the current environment.
